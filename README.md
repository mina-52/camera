# 動画物体検出システム (pretest-mv.py)

## 概要

このプログラムは、指定した動画ファイルに対してYOLOv8モデルを使用したリアルタイム物体検出を実行します。画面は常に四分割で表示され、左上/左下の挙動は0.5秒刻みで同期して更新されます。

## 機能

- **動画ファイルからの物体検出**: 指定した動画ファイルに対してYOLOv8モデルで物体検出を実行
- **常時四分割画面表示**:
  - 左上: 0.5秒ごとに自動更新する検出物体の切り抜き（最も高い信頼度、ラベル/信頼度表示、一時停止/再開可能）
  - 右上: リアルタイム検出結果（バウンディングボックス付き）
  - 左下: 同一フレームで2つ以上検出がある場合のみ更新（左上と同期）。左上と同じラベルのうち2番目に高い信頼度を優先、なければ全体2番目を表示。2件未満のフレームでは前回の画像を継続表示
  - 右下: 検出数、左上/左下のラベルと信頼度、フレームカウンター、状態表示
- **フルスクリーン表示**: 四分割をフルスクリーンで表示
- **一時停止/再開機能**: エンターキーで左上の更新を一時停止/再開（左下もタイミングを同期）
- **画像保存機能**: 一時停止時に検出された物体の画像を自動保存
  - `randoruto`フォルダー内にセッション別フォルダーを作成
  - 全ての検出物体にバウンディングボックスとラベル・信頼度を表示した画像を保存
  - ファイル名形式: `detection_frame{フレーム番号}_{検出物体数}objects.jpg`

## 必要なファイル

- `pretest-mv.py`: メインプログラム
- `weights.pt`: 学習済みYOLOv8モデルファイル
- 動画ファイル（例: `DJI_0008.MOV`）

## インストール

必要なPythonパッケージをインストールしてください：

```bash
pip install opencv-python
pip install ultralytics
pip install numpy
```

## 使用方法

### 基本的な使用方法

```bash
python pretest-mv.py
```

デフォルトで `C:\DJI_0008.MOV` を使用します。別の動画を使う場合は `--video` を指定してください。

### 動画ファイルを指定する場合

```bash
python pretest-mv.py --video your_video.mp4
```

### 使用例

```bash
# デフォルトの C:\DJI_0008.MOV を使用
python pretest-mv.py

# 特定の動画ファイルを指定（相対パス）
python pretest-mv.py --video sample.mp4

# フルパスで動画ファイルを指定（Windows）
python pretest-mv.py --video C:\path\to\your\video.mp4

# フルパスで動画ファイルを指定（Unix系）
python pretest-mv.py --video /path/to/your/video.mp4
```

## 操作方法

- **エンターキー**: 左上の画像更新を一時停止/再開
  - 再生中に押す: 一時停止（検出画像を自動保存）
  - 一時停止中に押す: 現在のフレームまで飛ばして再開（左下も同期）
- **qキー**: プログラム終了

## 画面レイアウト（常時四分割）
```
┌─────────────────┬─────────────────┐
│                 │                 │
│   左上          │   右上          │
│ 0.5秒ごと       │ リアルタイム    │
│ 自動更新        │ 検出結果        │
│ (一時停止可)     │                 │
│                 │                 │
├─────────────────┼─────────────────┤
│                 │                 │
│   左下          │   右下          │
│ 同時2検出時更新 │ 検出数/情報     │
│（同ラベル優先） │ フレーム/状態   │
│ それ以外継続    │                 │
└─────────────────┴─────────────────┘
```

## 表示される情報

### 左上画面
- 0.5秒ごとに更新される検出物体の切り抜き画像（最も高い信頼度）
- ラベルと信頼度表示（例: `drone: 0.923`）
- 状態表示（"PLAYING" / "PAUSED"）

### 左下画面
- 同時に2つ以上検出されたフレームでのみ更新
- 左上と同じラベルの2番目に高い信頼度を優先、なければ全体2番目
- 2件未満のフレームでは前回画像を継続表示

### 右下画面
- 検出数
- 左上/左下のラベルと信頼度
- フレームカウンターと状態

## 対応動画形式

OpenCVがサポートする形式：
- MP4 (.mp4)
- AVI (.avi)
- MOV (.mov)
- MKV (.mkv)
- その他OpenCVがサポートする形式

## 保存される画像

### 保存場所
- `randoruto/session_YYYYMMDD_HHMMSS/` フォルダー内
- 一回の実行につき一個のセッションフォルダーを作成

### 画像内容
- 元のフレームに全ての検出物体のバウンディングボックスを表示
- 各検出物体にラベルと信頼度のテキストを追加
- ファイル名例: `detection_frame123_3objects.jpg` (フレーム123で3個の物体を検出)

### 保存タイミング
- エンターキーで一時停止した際に自動保存
- 検出物体がある場合のみ保存

## トラブルシューティング

### 動画ファイルが開けない場合
- ファイルパスが正しいか確認
- 動画ファイルが存在するか確認
- 動画ファイルが破損していないか確認

### モデルファイルが見つからない場合
- `weights.pt`ファイルが同じディレクトリにあるか確認
- モデルファイルのパスが正しいか確認

### 表示が正常でない場合
- OpenCVが正常にインストールされているか確認
- 画面解像度が適切か確認
