# 動画物体検出システム (pretest-mv.py)

## 概要

このプログラムは、指定した動画ファイルに対して2つのYOLOv8モデルを使用したリアルタイム物体検出を実行します。メインモデル（weights.pt）と数字認識モデル（number.pt）を同時に使用し、四分割画面で検出結果を表示します。一時停止時に検出画像を自動保存する機能も備えています。

## 機能

- **デュアルモデル物体検出**: 
  - メインモデル（weights.pt）: 一般的な物体検出
  - 数字認識モデル（number.pt）: 数字認識（信頼度90%以上）
- **四分割画面表示**: 
  - 左上: 0.5秒ごとに自動更新される検出物体の切り抜き画像（一時停止/再開可能）
  - 右上: メインモデルのリアルタイム検出結果（バウンディングボックス付き）
  - 左下: 二重検出時のみ更新される2番目の検出物体画像
  - 右下: 数字認識モデルの検出結果（バウンディングボックス付き、信頼度90%以上）
- **フルスクリーン表示**: 検出結果をフルスクリーンで表示
- **自動更新機能**: 左上の画像が0.5秒ごとに自動更新
- **一時停止/再開機能**: エンターキーで左上の更新を一時停止/再開
- **画像自動保存機能**: 一時停止時に検出画像を自動保存
- **高精度フィルタリング**: 数字認識モデルは信頼度90%以上の検出のみを表示
- **信頼度ベース選択**: 検出物体を信頼度でソートして最適なものを選択

## 必要なファイル

- `pretest-mv.py`: メインプログラム
- `weights.pt`: メイン学習済みYOLOv8モデルファイル
- `number.pt`: 数字認識用YOLOv8モデルファイル
- 動画ファイル（例: `akarui-ari.mp4`）

## インストール

必要なPythonパッケージをインストールしてください：

```bash
pip install opencv-python
pip install ultralytics
pip install numpy
```

## 使用方法

### 基本的な使用方法

```bash
python pretest-mv.py
```

デフォルトで`akarui-ari.mp4`ファイルを使用します。

### 動画ファイルを指定する場合

```bash
python pretest-mv.py --video your_video.mp4
```

### 使用例

```bash
# デフォルトのakarui-ari.mp4を使用
python pretest-mv.py

# 特定の動画ファイルを指定
python pretest-mv.py --video sample.mp4

# フルパスで動画ファイルを指定
python pretest-mv.py --video /path/to/your/video.mp4
```

## 操作方法

- **エンターキー**: 左上の画像更新を一時停止/再開
  - 再生中に押す: 一時停止（検出画像を自動保存）
  - 一時停止中に押す: 現在のフレームまで飛ばして再開
- **qキー**: プログラム終了

```
┌─────────────────┬─────────────────┐
│                 │                 │
│   左上          │   右上          │
│ 0.5秒ごと       │ メインモデル    │
│ 自動更新        │ 検出結果        │
│ (一時停止可能)   │                 │
│ 信頼度表示      │                 │
│                 │                 │
├─────────────────┼─────────────────┤
│                 │                 │

```

## 表示される情報

### 左上画面
- 0.5秒ごとに更新される検出物体の切り抜き画像
- 状態表示（"PLAYING" / "PAUSED"）
- ラベルと信頼度表示
- 緑色: 再生中、赤色: 一時停止中

### 右上画面
- メインモデル（weights.pt）のリアルタイム検出結果
- バウンディングボックスとラベル付き

### 左下画面
- 二重検出時のみ更新される2番目の検出物体画像
- 同じラベルの2番目の検出を優先表示
- ラベルと信頼度表示
- 検出がない場合は前回の画像を継続表示

### 右下画面
- 数字認識モデル（number.pt）の検出結果
- 信頼度90%以上の検出のみを表示
- バウンディングボックスとクラス名・信頼度ラベル付き

## 画像保存機能

### 保存場所
- `randoruto/`フォルダー内にセッション別フォルダーを作成
- フォルダー名: `session_YYYYMMDD_HHMMSS`

### 保存タイミング
- エンターキーで一時停止した時点で自動保存
- 検出物体がある場合のみ保存

### 保存内容
- 検出物体にバウンディングボックスとラベルを描画した画像
- ファイル名: `detection_frame{フレーム番号}_{検出物体数}objects.jpg`
- 保存統計情報をプログラム終了時に表示

## 対応動画形式

OpenCVがサポートする形式：
- MP4 (.mp4)
- AVI (.avi)
- MOV (.mov)
- MKV (.mkv)
- その他OpenCVがサポートする形式

## トラブルシューティング

### 動画ファイルが開けない場合
- ファイルパスが正しいか確認
- 動画ファイルが存在するか確認
- 動画ファイルが破損していないか確認

### モデルファイルが見つからない場合
- `weights.pt`ファイルが同じディレクトリにあるか確認
- `number.pt`ファイルが同じディレクトリにあるか確認
- モデルファイルのパスが正しいか確認

### 表示が正常でない場合
- OpenCVが正常にインストールされているか確認
- 画面解像度が適切か確認

### 画像保存ができない場合
- `randoruto`フォルダーに書き込み権限があるか確認
- ディスク容量が十分にあるか確認
