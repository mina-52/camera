# 物体検出システム統合管理ツール

## 概要

このプロジェクトは、複数の物体検出プログラムを統合管理するシステムです。`main.py`を使用してプログラムを簡単に切り替えることができ、各プログラムは異なる検出用途に特化しています。

## main.py - プログラム切り替えシステム

### 機能
- **統合管理**: 複数の検出プログラムを1つのインターフェースで管理
- **簡単切り替え**: 数字キーでプログラムを瞬時に切り替え
- **安全な停止**: 実行中のプログラムを確実に停止してから新しいプログラムを起動
- **リアルタイム状態表示**: 各プログラムの実行状態をリアルタイムで確認

### 使用方法

```bash
python main.py
```

### 操作方法
- **1**: `randoruto-number.py` - ナンバー検出（基本版）
- **2**: `randoruto.py` - ランドルト環検出（標準版）
- **3**: `sabi-obs.py` - 錆検出システム
- **4**: `kikenbutu.py` - 危険物検出
- **5**: `drone_detection copy.py` - ドローン検出
- **q**: システム終了

### メニュー画面
```

==================================================
1. randoruto-number.py (停止中)
2. randoruto.py (実行中)
3. sabi-obs.py (停止中)
4. kikenbutu.py (停止中)
5. drone_detection copy.py (停止中)
q. 終了

```

## 各プログラムの詳細機能

### 1. randoruto-number.py - ナンバー検出（基本版）

**概要**: 基本的なナンバープレート等の検出を行うプログラム

#### 主な特徴
- **使用モデル**: `weights.pt`
- **保存フォルダ**: `randoruto-number/`
- **検出対象**: 数字・文字などのナンバー類
- **四分割画面**: リアルタイム検出結果を4画面で表示
- **画像保存**: 一時停止時に検出画像を自動保存

#### 操作方法
- **エンターキー**: 一時停止/再開
- **qキー**: プログラム終了

---

### 2. randoruto.py - ランドルト環検出（標準版）

**概要**: ランドルト環（視力検査用の環形記号）の高精度検出システム

#### 主な特徴
- **使用モデル**: `weights.pt`
- **保存フォルダ**: `randoruto/`
- **検出対象**: ランドルト環（視力検査用記号）
- **高精度検出**: 0.5秒間隔での自動更新と同期制御
- **詳細分析**: 信頼度ソート、複数検出時の優先順位制御

#### 四分割画面レイアウト
```
┌─────────────────┬─────────────────┐
│ 右上: リアルタイム │ 左上: 最高信頼度  │
│ 検出結果         │ 0.5秒更新      │
│ (バウンディング   │ (一時停止可能)   │
│  ボックス付き)    │                │
├─────────────────┼─────────────────┤
│ 右下: 検出情報    │ 左下: 第2検出    │
│ フレーム/状態    │ (同ラベル優先)   │
│ 信頼度詳細       │ 継続表示        │
└─────────────────┴─────────────────┘
```

#### 画像保存機能
- **保存タイミング**: エンターキーでの一時停止時
- **ファイル形式**: 
  - `detection_frame{番号}_{検出数}objects.jpg` - 全体画像
  - `detection_frame{番号}_rightup_{ラベル}_{信頼度}.jpg` - 右上切り抜き
  - `detection_frame{番号}_rightdown_{ラベル}_{信頼度}.jpg` - 右下切り抜き

---

### 3. sabi-obs.py - 錆検出システム

**概要**: OBS仮想カメラを使用した高度な錆検出・分析システム

#### 主な特徴
- **使用モデル**: `sabi.pt` - 板検出専用モデル
- **保存フォルダ**: `sabi/`
- **検出手法**: YOLO板検出 + HSV色空間錆分析
- **カメラ入力**: OBS仮想カメラ（インデックス1）
- **詳細分析**: 錆面積、錆比率、板別詳細分析

#### 技術仕様
- **HSV色空間分析**: 錆特有の色範囲検出
  - 色相範囲: H(5-20), 彩度: S(80-255), 明度: V(40-200)
- **ノイズ除去**: モルフォロジー演算による精密化
- **輪郭検出**: 有効錆領域のフィルタリング
- **面積計算**: ピクセル単位での正確な錆面積測定

#### 保存される分析結果
1. **錆検出画像**: `rust_detection_{timestamp}_{frame}.jpg`
2. **板別錆マスク**: `plate_{ID}_rust_mask_{timestamp}_{frame}.jpg`
3. **錆分析画像**: `plate_{ID}_rust_analysis_{timestamp}_{frame}.jpg`
4. **詳細分析レポート**: `rust_analysis_{timestamp}_{frame}.txt`

#### 分析情報表示
- 検出板数
- 錆スポット総数
- 総錆面積（ピクセル）
- 錆比率（％）
- 板別詳細（最大2板まで画面表示）

## システム要件

### 必要なPythonパッケージ
```bash
pip install opencv-python
pip install ultralytics
pip install numpy
pip install tkinter  # 通常は標準ライブラリ
```

### 必要なファイル
- **main.py**: 統合管理システム
- **各検出プログラム**: randoruto.py, randoruto-number.py, sabi-obs.py など
- **学習済みモデル**: 
  - `weights.pt` - ランドルト環/ナンバー検出用
  - `target.pt` - ターゲット検出用
  - `sabi.pt` - 板・錆検出用

### OBS Studio設定（sabi-obs.py使用時）
1. OBS Studioをインストール
2. 「仮想カメラを開始」を実行
3. カメラインデックス1で設定

## トラブルシューティング

### main.pyでプログラムが切り替わらない場合
- Ctrl+Cでmain.pyを一度終了し、再起動してください
- 実行中のプログラムが応答しない場合、タスクマネージャーでプロセスを強制終了

### OBS仮想カメラが認識されない場合
- OBSで「仮想カメラを開始」しているか確認
- カメラインデックスを0, 1, 2など順番に試してください
- 他のアプリケーションがカメラを使用していないか確認

### モデルファイルが見つからない場合
- `weights.pt`, `target.pt`, `sabi.pt`が正しいディレクトリにあるか確認
- ファイル名の大文字小文字が正確か確認

### 画像が保存されない場合
- 書き込み権限があるディレクトリか確認
- ディスク容量が十分にあるか確認
